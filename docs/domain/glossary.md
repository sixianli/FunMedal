# FunMedal 术语表

这里定下项目文档和界面上固定的说法。每个词只写它是什么，不写它怎么实现。项目负责人 2026-10-24 在需求访谈第二轮确认。

## 范围

FunMedal 卡片和 Mac 上的桥接程序（把 Claude Code 和卡片连起来的程序）之间，关于“显示 Claude Code 状态”这一件事的用词。

## 用语

- **项目**：Claude Code（Anthropic 公司的 AI 编程助手）打开的一个代码目录，通常就是一个 Git 仓库。
  _Avoid_：仓库、目录、工作区（这些词在别的语境里有别的意思）。
- **会话**：一个项目里的一段对话。Claude 桌面 App 里叫 thread，Claude Code 自己叫 session。一个项目可以同时开几个会话。卡片上一行显示一个会话。
  _Avoid_：任务、线程、thread、session（文档里统一写“会话”，第一次出现时可以括注英文）。
- **会话状态**：一个会话此刻处于下面四种之一。
  - **在跑**：Claude 正在生成回答或执行工具。
  - **等你**：Claude 停下来等人做决定。包括权限请求（要跑命令、改文件，等你点允许）、选择题（AskUserQuestion，让你选一项）、计划确认（计划写完等你点“开始执行”）。卡片上不区分这三种，因为都要去电脑或手机上处理。
  - **答完了**：这一轮回答结束，Claude 闲着等你的下一句话。
  - **出错**：会话因为出错停了，比如网络断了、额度用完。
  会话关掉后从卡片上消失，不算一种状态。
  _Avoid_：干活中、等你批准、完成了、出错了、空闲（这是 2026-10-24 之前卡片上的五种说法，其中“空闲”和“完成了”合并成“答完了”，“等你批准”扩成“等你”）。
- **需要介入**：有至少一个会话处于“等你”。
  _Avoid_：待批准、pending。
